# Configuration Reference

All configuration is managed through environment variables. In development, these are loaded from a `.env` file. In Docker, they're injected by the container runtime.

## Settings

| Variable | Type | Default | Description |
|---|---|---|---|
| `BROKER_DB_URL` | string | `postgresql+psycopg://...@broker-db:5432/ephemeralshield` | Control-plane database connection string |
| `REDIS_URL` | string | `redis://redis:6379/0` | Redis connection URL |
| `LEASE_DEFAULT_TTL_SECONDS` | int | `1800` (30 min) | Default lease duration when user doesn't specify |
| `LEASE_MAX_TTL_SECONDS` | int | `7200` (120 min) | Absolute maximum lease duration |
| `WORKER_SCAN_INTERVAL_SECONDS` | float | `1.0` | How often the worker scans for expired leases |
| `AUDIT_SIGNING_KEY_PATH` | string | `./secrets/audit-signing.key` | Path to Ed25519 private key for checkpoint signing |
| `LOG_LEVEL` | enum | `INFO` | Logging level: DEBUG, INFO, WARNING, ERROR, CRITICAL |
| `ENVIRONMENT` | enum | `development` | Environment: development, staging, production |
| `APP_HOST` | string | `0.0.0.0` | API bind address |
| `APP_PORT` | int | `8000` | API bind port |

## Test Target Settings

These are only used in integration tests and are NOT needed in production.

| Variable | Type | Default | Description |
|---|---|---|---|
| `TEST_TARGET_DB_HOST` | string | `test-target-db` | Test target hostname |
| `TEST_TARGET_DB_PORT` | int | `5432` | Test target port |
| `TEST_TARGET_DB_USER` | string | `target_admin` | Test target admin user |
| `TEST_TARGET_DB_PASSWORD` | SecretStr | — | Test target password (redacted in logs) |
| `TEST_TARGET_DB_NAME` | string | `target_app` | Test target database name |

## Development vs. Production Differences

| Setting | Development | Production |
|---|---|---|
| `LOG_LEVEL` | `DEBUG` | `INFO` or `WARNING` |
| `ENVIRONMENT` | `development` | `production` |
| API docs | Enabled (`/docs`, `/redoc`) | Disabled |
| CORS | Localhost origins allowed | Disabled (mTLS proxy handles it) |
| SQLAlchemy echo | Enabled (SQL logging) | Disabled |
| Database ports | Mapped to host (127.0.0.1) | Not exposed |

## Secret Management

| Secret | Development | Production |
|---|---|---|
| Database passwords | Generated by `scripts/generate-secrets.ps1` | Secret manager (Vault, AWS SM, etc.) |
| Audit signing key | Local PEM file in `secrets/` | Mounted secret file |
| mTLS certificates | Generated CA (Phase 3) | Properly issued certificates |
| `.env` file | Local file (gitignored) | Not used — env vars from runtime |
